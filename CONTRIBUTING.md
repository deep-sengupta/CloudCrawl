# Contributing to CloudCrawl

Thank you for your interest in contributing to CloudCrawl.

## Making Changes

When contributing:

1. Keep changes focused and relevant to the proposed improvement.
2. Follow the existing Python code style and project structure.
3. Add or update documentation when introducing or changing user-facing features.
4. Avoid unrelated changes in the same contribution.
5. Keep the implementation simple and consistent with the existing project.

## Pull Requests

When opening a pull request:

- Clearly describe what was changed.
- Explain the reason for the change.
- Keep the pull request focused and easy to review.
- Include any relevant documentation updates.
- Avoid unnecessary changes to unrelated files.

## Suggestions and Improvements

Contributions can include:

- Bug fixes
- New features
- Improvements to existing functionality
- Documentation improvements
- Test improvements
- Performance or usability improvements

Every contribution should aim to make CloudCrawl more reliable, useful, and maintainable.

Thank you for helping improve CloudCrawl.
